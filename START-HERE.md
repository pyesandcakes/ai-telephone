# Run AI Telephone

**Mac:** double-click `Start-AI-Telephone.command`.

**Windows:** double-click `Start-AI-Telephone.cmd`.

The launcher guides you through installing Python 3.12 and Ollama if missing, installs the project dependencies, downloads missing models, and opens the controller. First setup needs internet and several GB of disk space. No paid API key is needed. If model access requires authentication, use your own Hugging Face account.

When the controller opens, enter a starting prompt and click **Start live demo**. Click **Present on this laptop** for the combined display. Keep the terminal open. Click **Stop** and wait before closing it.

For continuous generation, select **Continuous testing** in the controller. For saved playback, select a run in the archive and click **Replay run**.

Other display laptops need only a browser and the host's display URL; they do not need Python or models.

See [README.md](README.md) for setup details, troubleshooting, accounts, recording, and LAN displays.
